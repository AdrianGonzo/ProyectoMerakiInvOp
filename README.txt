Para construir el proyecto se debe crear la base de datos en postgreSql con el archivo SQL en
el archivo del proyecto con el nombre que tiene dicho archivo. Se debe hacer el buildpath de las
librerias usadas
	-Click Derecho->BuildPath->Configure Path->Libraries->Add external JAR->
		->"Añadir los archivos que estan en la carpeta lib: postgres, JCalendar"->
		->Apply

Cambiar los datos de usuario, contraseña y puerto en el archivo Conexion.java

Para ejecutar el proyecto haga un run desde el archivo Main.
